## ✅ Реализованные требования

### 1. Ввод / вывод

| Конструкция | Где используется |
|-------------|------------------|
| `prompt()` | Запрос имени пользователя при загрузке страницы |
| `alert()` | Приветствие пользователю по имени |
| `alert()` | Итоговый вывод: «Среднее время работы – X часов, Y устройств – долгожители» |
| `console.log()` | Логирование данных, расчётов и предупреждений |

### 2. Условные конструкции и циклы

- `if / else` — проверка имени, проверка среднего времени (< 6 часов), проверка малого времени (≤ 4 часов).
- `for` — перебор массива в функциях `findMax`, `filterLongLasting`, `sumArray`, подсчёт устройств с малым временем.
- Тернарный оператор — вывод результата проверки среднего времени в блок на странице.

### 3. Функции для работы с массивом

| Функция | Назначение |
|---------|-----------|
| `findMax(arr)` | Поиск максимального значения в массиве |
| `filterLongLasting(arr, threshold)` | Фильтрация элементов > порога (по умолчанию 8 часов) |
| `sumArray(arr)` | Сумма всех элементов массива |
| `average(arr)` | Среднее значение массива (использует `sumArray`) |

## 📊 Данные и логика (Вариант 12)

### Массив данных

```javascript
const batteryHours = [12, 5, 3, 9, 4, 15, 7];
```

7 чисел — время автономной работы гаджетов в часах.

### Логика

1. **Фильтрация** — гаджеты с временем работы > 8 часов (долгожители).
2. **Цикл** — устройства с малым временем (≤ 4 часов) и их доля от общего числа.
3. **Функции** — максимум, фильтрация, сумма.
4. **Вывод в `alert`**: «Среднее время работы – X часов, Y устройств – долгожители».
5. **Вывод в `console`**: доля устройств с малым временем и их количество.
6. **Дополнительно**: если среднее < 6 часов → в консоль выводится «Стоит обратить внимание на энергоэффективность».

## 🧪 Пример работы

Для массива `[12, 5, 3, 9, 4, 15, 7]`:

| Показатель | Значение |
|------------|----------|
| Сумма | 55 ч |
| Среднее | ≈ 7.86 ч |
| Максимум | 15 ч |
| Долгожители (> 8 ч) | `[12, 9, 15]` — 3 шт. |
| Малое время (≤ 4 ч) | `[3, 4]` — 2 шт. |
| Доля малого времени | ≈ 28.6% |
| Среднее < 6 ч? | Нет → «Энергоэффективность в норме» |

### Что видит пользователь

1. Браузер запрашивает имя (`prompt`).
2. Появляется `alert` с приветствием.
3. После расчётов — `alert` с итогом: «Среднее время работы – 7.86 часов, 3 устройств – долгожители».
4. В **Console** (F12) — все логи:
   ```
   Пользователь: <имя>
   --- Анализ времени автономной работы ---
   Время автономной работы (часы): (7) [12, 5, 3, 9, 4, 15, 7]
   Максимум (часов): 15
   Долгожители (>8 ч): (3) [12, 9, 15] — количество: 3
   Сумма всех часов: 55
   Среднее время работы: 7.86 часов
   --- Устройства с малым временем (≤ 4 ч) ---
   Количество: 2
   Их значения (часы): (2) [3, 4]
   Доля от всех устройств: 28.6%
   ✅ Энергоэффективность в норме
   ```
